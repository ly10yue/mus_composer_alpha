# 0.12.0：版本、坐标与迁移

Android 游戏、Windows 制谱器、Agent 工具与新导出文件统一为 **0.12.0**。Android versionCode 为 12；Windows EXE 的文件版本和产品版本也为 0.12.0。游戏底部、制谱器标题显示程序版本，选歌详情显示谱面来源版本。

## 新文件

`.ivproj` 工程及 `.interval` 内的 `chart.json` 根节点包含：

```json
{
  "version": 6,
  "appVersion": "0.12.0",
  "minReaderVersion": "0.12.0",
  "coordinateScale": 100
}
```

`version` 是文件结构版本；`appVersion` 是写入程序版本；`minReaderVersion` 声明最低读取版本。它们不能混为同一个字段。工程空间数据在 `document` 中；谱面空间数据在根节点中。工程时间为拍，谱面时间为秒。

| 参数 | 0.12.0 单位 | 示例 |
| --- | --- | --- |
| 轨迹 frames.x、events.x.from/to | 横向 0–100 | 居中 50 |
| 区域 rects | `[左,上,右,下]`，0–100 | 全屏 `[0,0,100,100]` |
| 区域 motions.x/y | 相对位移，±200 | 向上 25：y=-25 |
| 区域 events.center | 绝对中心 `[X,Y]`，-200–300 | `[25,75]` → `[25,25]` |
| 区域 events.width/height | 横向 / 纵向尺寸，0.1–400 | 全屏 100 × 100 |
| angle、alpha、speed | 度、0–1、倍率 | 90、0.5、1 |
| beat、time、BPM | 拍、秒、每分钟拍数 | 不乘 100 |

新线默认无音符、位置 50、透明度 0、流速 1。新区域默认全屏、旋转 0°，支持命名；区域名称为与 rects 对齐的可选 `names` 数组。

## 从 Composer 0.11.0 迁移

0.11.0 曾按所用功能输出 v3、v4 或 v5，未统一写入 appVersion；因此以结构版本识别其归一化坐标。打开旧 `.ivproj`、`.json` 或 `.interval` 时，0.12.0 自动读取旧单位，界面显示百分制；重新保存 / 导出时写入 v6。Android 0.12.0 也能直接游玩旧包，不要求先经过制谱器转换。

只有空间字段扩大 100 倍：位置、矩形、位移、中心、宽高。时间、角度、透明度、流速保持不变。内部几何仍使用归一化单位，并在输入 / 输出边界转换，因此视觉与判定保持一致；重复保存不会再次扩大。导入不会改写原文件，建议另存新版本。

格式 v6 必须声明 coordinateScale=100。旧格式与 coordinateScale=100 混用、未知结构版本、要求更高 minReaderVersion 的文件会被拒绝，避免猜单位或静默丢失功能。兼容同一结构且 minReaderVersion 不高于当前程序的文件。旧版游戏不能读取 v6，更新游戏后再导入新版谱面。

已有更早版本读取分支暂时保留，但此次兼容与回归基线为 Composer 0.11.0；不承诺更早版本的全部行为。

## 编辑变化

- 工具栏直接进入「区域 / 四栏编辑」，顶部选择、新建、命名、删除区域，与线相同；默认全屏。中心、旋转、总长、总宽仍通过时间长条编辑。
- Ctrl 框选时将指针移至上下边缘，即逐格自动滚动；选择起点绑定原来的拍，不随画面漂移。松开 Ctrl / 鼠标或切换窗口停止。音符、线、区域时间轴都支持。
- 同时开放的区域按多边形并集合成外轮廓，隐藏交叠内部边缘；包括移动及旋转后的区域，实际判定仍为并集。
- Agent 的 15 个工具、界面数值和新剪贴板均使用百分制空间坐标。旧剪贴板仍可读取。区域编辑中选定的区域会成为 Agent 的「这个区域」目标。
