# 四栏轨迹编辑 · 2026-10-26

Windows 制谱器 0.10.2 / Android 0.9.0。

打开 `dist/editor-0.10.2/IntervalComposer/IntervalComposer.exe`，点击 **轨迹 / 四栏编辑**。根目录 `Start-Qoder-Agent.cmd` 也已指向新版。

| 栏 | 编辑内容 | 新线默认 | 可用数值 |
| --- | --- | --- | --- |
| 绑定音符 | Tap / Hold，自动绑定当前线 | 无音符 | 按拍放置 |
| 横向位置 | 线与所绑音符的横向轨迹 | 0.5 | 0–1 |
| 线透明度 | 轨迹线可见程度 | 0 | 0–1 |
| 音符流速 | 该线的下落速度倍率 | 1 | 0–8 |

四栏共用小节线、细分网格和下方固定判定线。网格仍可选按每拍 / 每小节的 1/2、1/4、1/6 等细分。滚轮向上进入后续小节，图形向下移动；向下回退；Ctrl＋滚轮缩放。

在后三栏的空白处按住鼠标拖出长条。长条确定起止拍，右侧填写起点值、终点值与变化类型，再点“应用选中长条”。长条内显示两端数值和变化曲线。可双击聚焦数值，拖中间移动整个区间，拖边缘改变起止，右键 / Delete 删除。当前选中的未应用数值也会在“确定”时校验并保存。

变化类型包括直线、Sin 缓入缓出、Sin 缓入、Sin 缓出、平滑 S 型，以及保持起值到末端切换。同一栏不能重叠；三栏各自独立。区间前使用初始值，间隙和末段之后保持上一区间终值。如果需要回到原值，添加一个返回区间。

例：4 拍一小节时，第二小节至第四小节起点为第 4–12 拍。在位置栏画 4–12 拍的长条，起点 0.2、终点 0.8、Sin 缓入缓出，即可让轨迹从左向右过渡。透明度和流速可各自创建不同范围的长条。

Tap 横坐标仍由到达拍的轨迹位置决定；Hold 保留弯折形状并竖直下落。速度变化用区间积分计算距离：`距离 = ∫当前拍→音符拍 流速(拍) d拍`，再乘显示比例。这样改变速度不会导致音符位置突然跳跃，音符仍在原定判定拍到达下方判定线。四栏和主音符编辑网格始终按音乐拍排列；右侧游戏预览显示实际变速效果。

透明度仅影响线，音符仍可见。全局预览流速及 Android 的下落时间设置在此基础上叠加，不改变歌曲速度。音频仍使用上一版的采样对齐试听。

工程保留拍单位；导出 JSON 中区间起止转换为秒。包含区间事件时使用 v4 格式，需安装 `dist/Interval-0.9.0.apk`；旧 v1/v2/v3 谱面可继续打开，纯旧关键帧谱面仍可导出 v3。AT Flow 原谱保留。

输入修复包括：定时刷新不再覆盖正在输入的数字；暂停定位保留填写的精确拍数；输入框内的全选、复制粘贴和左右键正常工作；上下箭头使用明确的图标与可点区域，小数参数有合适的步长。
