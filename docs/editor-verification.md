# 0.2.0 制谱器验证

日期：2026-10-22。环境：Windows 11，Python 3.14，PySide6 6.11.0；Android 10 / API 29 模拟器。

- 模型测试 14 项通过：三连 / 六分网格、按小节细分、网格批量填充、Tap / Hold、BPM 两种重定时模式、区域覆盖分割、并集、撤销、工程与文件包回读、原示例往返、非法数字和区域间隙、ZIP 路径穿越拒绝。
- Qt 界面测试通过：实际点击与拖动放置音符、拖 Hold 尾部、撤销重做、复制粘贴和镜像、画布矩形拖画、区域时间段应用、保存 / 导出 / 重新打开，以及 OGG 实际加载、播放前进、暂停冻结、A–B 循环和自动恢复快照。
- 桌面窗口截图已检查：1440×940 与 1100×780，区域属性可滚动访问。
- 跨端联调 12 项通过：使用桌面 UI 测试实际导出的 `.interval`，在 Android 中导入，检查标题、Tap / Hold 时间、上下区和双区间隙，并用原生 MediaPlayer 实际播放及自动判定。
- 原游戏回归：28 项判定检查和 30 / 60 / 120 FPS 整曲模拟通过；新版 4:3 Android 运行检查 13 项通过。

Windows 可执行文件单独进行 `--verify-output` 检查并通过：`frozen=true`、622 个示例音符、音频加载成功且实际播放前进。结果保存在 `build/composer-verified.json`。打包检查修正了环境中同名 ICU DLL 被误收集的问题，构建脚本现在使用 Qt 所需的 Windows 系统 ICU。测试资源和诊断入口不影响正常启动。

本次 Android 联调仍为模拟器，未增加物理手机测试。当前编辑器支持恒定 BPM、分段静态矩形与单曲工程；变速 BPM、区域动画、曲库管理不在此版中。
