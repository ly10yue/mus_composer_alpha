# 0.12.0 制谱器检查修正

- 取消“需要超过两根手指”的多押警告。
- 音符同列重叠降为警告，保留相关音符并允许导出；检查结果保留提醒。
- 导出时警告仅显示在状态栏，不再弹出确认；真正的错误仍然阻止导出。
- 音符相关错误和警告使用 `分:秒.毫秒（第 N 拍）` 定位，包含歌曲 offset。Hold 的起点与中途离开区域的位置均显示时间，不使用内部音符 ID。
- 区域时间轴不连续、同一参数栏事件重叠属于结构错误，仍需修复。此修正针对音符重叠，不改变文件格式或游戏判定。

修正版：`dist/editor-0.12.0-checkfix/IntervalComposer/IntervalComposer.exe`。主版本及谱面格式继续为 0.12.0 / v6，与原 APK 兼容。

验证：73 项 Python 单元测试通过，包含四押不警告、重叠包完整导出、时间点与偏移；另验证导出入口没有警告确认弹窗。
