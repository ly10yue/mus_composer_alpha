# INTERVAL Composer · 电脑制谱器

与 Android 游戏同一工程内的原生 Windows 制谱器。使用 Python / PySide6，基础编辑离线运行，Agent 按需连接配置的 API；工程内部按拍编辑，导出时转换为秒数。所有工程与谱面统一输出格式 v6，需要 Android 0.12.0。支持读取 Composer 0.11.0 的旧文件，并自动转换空间坐标。

## 打开

0.10.0 新增四栏轨迹编辑：绑定音符、横向位置、线透明度、音符流速。修复时间输入被刷新覆盖、输入快捷键冲突，统一数字箭头显示；滚轮方向调整为向上进入后续小节。操作与格式见 [四栏轨迹编辑](../docs/track-events.md)。

开发运行：在工程根目录执行 `python editor/main.py`，或双击 `editor/start.cmd`。依赖安装：

## 第一次制谱

1. 点击 **导入歌曲**，选择 OGG / MP3 / WAV / M4A / FLAC / AAC。也可以点击 **示例谱面** 编辑内置曲目的副本。
2. 打开 **歌曲 / BPM / 偏移**，填写 BPM、每小节拍数、作者和难度。默认 4 拍一小节。正偏移表示第 0 拍晚于音乐开始。
3. 工具栏选择网格单位 **每拍** 或 **每小节**，再选 `1/1、1/2、1/3、1/4、1/6、1/8、1/12、1/16、1/24、1/32`。
4. 选择 Tap 后点击网格放置；选择 Hold 后从起点向上拖出尾部，越靠上代表越晚的拍。
5. 播放试听，可开启节拍器、减速到 0.5× / 0.75×，或设置 A–B 循环。
6. 保存 `.ivproj` 工程；检查谱面后导出 `.interval` 包，传入手机。
7. 安装本工程 **0.12.0 APK**，点击 **进入选歌 → 导入谱面**，从系统文件选择器选中 `.interval`。导入后音乐会复制进应用内部，选中新谱面后点击 **开始演奏** 即可离线游玩；内置歌曲和所有导入谱面都保留在选歌列表中。

## 节拍与时间

网格中的拍数从 **0** 开始，小节标签从 **1** 开始。例如每小节 4 拍时，第 2 小节的起点是第 4 拍。

| 网格设置 | 相邻格距离（每小节 4 拍时） |
| --- | --- |
| 每拍 · 1/4 | 0.25 拍 |
| 每拍 · 1/6 | 1/6 拍 |
| 每小节 · 1/4 | 1 拍 |
| 每小节 · 1/6 | 2/3 拍 |

音符实际播放时刻：`拍数 × 60 / BPM + offset`。BPM 编辑提供两种模式：

- **保留拍位置**：音符、轨迹关键帧与区域仍在原来的拍数，实际秒数改变。
- **保留实际时间**：音符、轨迹关键帧与区域的实际秒数不变，重新计算其拍数。

当前支持单一恒定 BPM，尚未加入变速 BPM 事件。波形在音频后台解码完成后显示，时间轴左侧显示当前已完成的波形包络；波形不是音量控制。

## 编辑音符

编辑区采用下落式时间轴：判定线固定在视口高度的 80%，代表当前播放拍。未来的小节线、Tap 和 Hold 位于上方，播放时一同向下移动；已过去的内容位于线下。暂停后保持当前画面。缩放只改变拍间距，不改变当前拍或判定线位置。

- `Q`：Tap；`R`：Hold；`V`：选择。
- 选择模式下拖动音符改变所绑轨迹和拍位置；拖动 Hold 尾部修改持续拍数。
- 双击音符打开属性，可精确填写开始拍、所绑轨迹 与持续拍数。持续为 0 表示 Tap。
- `Ctrl`（或旧的 `Shift`）拖框多选，`Ctrl+A` 全选。
- `Ctrl+C / Ctrl+V` 复制并粘贴到当前游标，保留相对拍间距；左右镜像作用于当前选择。
- **按当前网格批量填充** 可指定起止拍和所绑轨迹，生成连续 Tap 或等长 Hold；结束拍不包含在范围内，Hold 长度不能超过格距。一次最多填充 2000 个，可整体撤销。
- `Delete` 或右键点击音符删除；`Ctrl+Z / Ctrl+Y` 撤销 / 重做，最多保存 100 步。
- 工具栏「绑定轨迹」选择具体轨迹时，新音符直接绑定该轨迹；选「自动」时按点击处最近的轨迹放置。多选音符后可用「选中音符绑定到当前轨迹」批量改绑。
- 左右镜像选择当前画面中镜像位置最近的已有轨迹；复制粘贴保留轨迹绑定。切换歌曲 / 工程会清空内部音符剪贴板。
- 鼠标滚轮每个刻度移动一格，取决于当前每拍/每小节细分（向上前进，向下回退），右侧滚动条也可定位；操作时暂停播放。`Ctrl+滚轮` 缩放拍间距；点击左侧刻度可将对应拍移到判定线上。左右方向键移动一格，空格播放 / 暂停。正在编辑数字时，方向键与复制粘贴作用于输入框。
- 下方拍数输入框和歌曲进度条也可定位。A / B 按钮将当前游标设为循环起止，B 必须晚于 A。

## 编写轨迹线

1. 点击 **轨迹 / 四栏编辑**，顶部选择轨迹，可新增、重命名或删除空线。新建工程与新线默认无音符、位置 50、透明度 0、流速 1。
2. 第 1 栏用 Tap / Hold 工具放置音符，自动绑定当前线。选择模式可移动音符或调整 Hold 两端。
3. 第 2–4 栏分别编辑位置、透明度和流速。在空白处沿时间轴拖出长条，右侧填写起止拍、起止值、变化类型，点击 **应用选中长条**。长条内显示曲线与端点值；双击长条可聚焦数值输入。
4. 支持直线、Sin 缓入缓出 / 缓入 / 缓出、平滑 S 型、保持起值到末端。位置为 0–100，透明度为 0–1，流速为 0–8 倍；0 可实现暂时停顿，1 为默认流速。流速只影响该线音符的视觉下落，不改变判定时间或音乐速度。
5. 拖动长条中部移动时间，拖两端改变范围，右键或 Delete 删除；同一栏不允许重叠，区间之间保持上一段终值，三栏可以独立重叠。旧关键帧自动显示为相邻帧之间的长条，首次修改某栏时保留该栏其余段。
6. 预览和四栏时间轴共用当前拍。**确定** 同时提交轨迹和音符，可在主界面一步撤销；**取消** 丢弃本次草稿。四栏内另有撤销 / 重做。新增区间谱面导出后，请使用 Android 0.12.0。

每谱 1–64 条轨迹，每条 1–256 帧。时间轴与右侧预览使用同一轨迹计算；轨迹与 Hold 的折线形状一起向下卷动，Hold 的头部、中段、尾部可处于不同横向位置；同一绝对拍的横坐标固定，只随时间改变屏幕高度。Tap 也保持横坐标固定、竖直下落。时间轴保留线下历史内容方便编辑，游戏预览将进行中的 Hold 头固定在下方判定线。

Tap 和 Hold 头判定使用音符起始拍对应的轨迹横坐标。已按下的 Hold 使用当前裁切点与下方固定判定线交点的横坐标。手指高度仍只受二维判定区域限制。Hold 期间需要跟随该横坐标，偏离超过 85ms 会断连。位置瞬移可能造成高难度滑动，请通过自动演示和手动试玩检查。

内置「示例谱面」和 `dist/Desultory-Signals-Vertical.interval` 均为新版。开场长 Hold 可直接观察弯折形状竖直下落；原有区域动画示例仍可导入。

## 编写判定区域

1. 点击工具栏 **区域 / 四栏编辑**，或右侧「判定区域」中的同名按钮。与轨迹一样，顶部选择、新建、重命名或删除区域。
2. 新区域默认全屏：中心 **(50,50)**、角度 **0°**、总长 **100**、总宽 **100**。生效段落下拉框用于选择已有谱面的不同时间段。
3. 四栏分别是中心点 X/Y、旋转角度、总长（横向）、总宽（纵向）。在时间轴拖出长条，设置起止拍、起止值和缓动，再点击「应用选中长条」。中心条同时填写 X 和 Y。
4. 「确定」整体应用并可一步撤销；「取消」不改主工程。对话框内也支持撤销、重做。每段最多 32 个区域，保留至少一个区域；导入的空段落仍可保留。
5. 多个区域按并集判定与显示，交叠内部的边缘隐藏。不同区域可以平移、旋转、伸缩；从左低右高变成上下组合时，使用连续时间条避免突然跳变。
6. 旧的段落覆盖、矩形拖画等工具保留在右侧「旧式分段 / 矩形工具」中，用于新增生效时间段等高级编辑。

空间输入为 **0–100**（中心与尺寸允许一定范围超屏），旋转为度，正方向顺时针；透明度仍是 0–1，流速仍为倍数。内部几何使用归一化单位，文件、工具和界面统一使用百分制坐标。时间仍按拍编辑，导出为秒。

按住 Ctrl 拖动框选音符或时间条；指针靠近上下边缘或移出边缘时自动沿网格滚动，松开 Ctrl 或鼠标即停止。Ctrl+C 复制、Delete 批量删除、Ctrl+V 粘贴：所选内容的最早起点落在当前判定线上，保留相对时间与通道。复制区域中心条时 X/Y 一同复制。所有普通滚轮刻度均移动当前细分的一格。

Hold 期间需要保持横向对位并跟随开放区域，建议同时预览 16:9 与 4:3。新区域默认全屏，缩放或旋转后的超屏部分不可点击。

## 文件与恢复

| 文件 | 用途 |
| --- | --- |
| `.ivproj` | 可继续编辑的工程，保存拍位置、BPM、网格、轨迹关键帧、区域及歌曲路径；不包含歌曲本体 |
| `.json` | 游戏 v6 谱面（兼容 0.11.0 旧格式），时间单位为秒；歌曲文件需另放在同目录 |
| `.interval` | 可移植 ZIP 文件包，内部为 `chart.json` 与 `music.扩展名`，包含歌曲本体 |

打开功能支持上述三种文件。工程引用的歌曲被移动后，可使用“导入歌曲”重新关联。移动工程到其他电脑时，优先导出 `.interval`，在另一台电脑打开后另存工程。

每 20 秒保存一次独立的自动恢复快照，不覆盖手动保存的工程；包含未应用的区域草稿。非正常退出后再次启动会询问恢复。正常保存 / 关闭会清理恢复快照。音乐替换会清空撤销历史，避免撤销到另一首歌曲的数据。

导出前检查会阻止歌曲缺失、音符超出音乐、同列重叠、不可触及的横向区域等错误，并提示多于双指的组合和跨区域的 Hold。生成的 JSON 与原生游戏共用格式，**不能直接打开 PhiEdit 私有工程或 Phigros 原谱**；现有 `tools/make_chart.py` 仍负责示例改编。
